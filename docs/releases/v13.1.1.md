# THOOP Android v13.1.1 — Automatic Hybrid History

**Build:** Android Full Debug, versionName `13.1.1-debug`, versionCode `557`.
**Source branch:** `fix/restore-vo2-vitality-detail-clean`.
**Release type:** Personal single-device update; local-first with encrypted Google Drive history.

## Changes since v13.1.0

- Rolling history bands: days 0–14 retain the full local-detail presentation; days 15–21 display compact summaries; days 22 and older are eligible for online history retrieval.
- Automatic snapshot refresh and scheduled encrypted Google Drive archive uploads; retries and catch-up when conditions permit.
- Day-specific online history preview via Backup & History, while retaining the existing monthly archive browser.
- One-time setup for automatic encrypted history, using the existing recovery passphrase protected locally with Android Keystore.
- Hardened Cloud Coach Worker source and tests. The Worker is a separately deployed service; this APK does not redeploy it.
- Existing Google Drive full-backup/recovery functionality remains separate and unchanged by the automatic-history schedule.

## Data preservation and requirements

- **No original local health data is deleted by this feature.** No cross-device synchronization is added.
- Automatic history requires completed one-time setup, usable Google Drive authorization, network connectivity, and Android background scheduling. Jobs can be delayed; a configured schedule does not itself prove a verified upload.
- Existing encrypted archives remain subject to passphrase recovery. The cloud view complements, rather than replaces, the local database.
- The build must retain the existing local `android/local.properties` Cloud Coach URL and Google OAuth client ID settings, or equivalent environment settings; building on unconfigured CI may disable those integrations.
- Install as an **update** to the existing matching-signature app. Never uninstall the app just to fix a signing mismatch.
